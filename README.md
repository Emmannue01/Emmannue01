## <img src="https://api.iconify.design/lucide/briefcase.svg?color=%232f81f7" width="26" height="26" align="absmiddle" /> Proyectos destacados

### <img src="https://api.iconify.design/lucide/landmark.svg?color=%232f81f7" width="24" height="24" align="absmiddle" /> Sitio oficial del municipio

**Qué es:** sitio web oficial e informativo sobre la gestión del municipio de Las Vigas, Guerrero: [lasvigasguerrero.gob.mx](https://lasvigasguerrero.gob.mx).

**Qué resuelve:** pone la información de la gestión municipal al alcance de la ciudadanía en un solo lugar, de forma pública y accesible.

**Tecnologías:** React

---

### <img src="https://api.iconify.design/lucide/hand-coins.svg?color=%232f81f7" width="24" height="24" align="absmiddle" /> Sistema de recaudación municipal

**Qué es:** sitio web y app móvil que funcionan como un sistema de recaudación de todo el municipio, centralizado en la tesorería municipal, con acceso por rol (tesorería, caja y dependencias).

**Qué resuelve:** centraliza en la tesorería la recaudación de todo el municipio, con un control claro de lo que se cobra y se recibe en lugar de llevarlo por separado en cada área.

**Tecnologías:** React · app móvil · Firebase / Supabase

---

### <img src="https://api.iconify.design/lucide/file-badge.svg?color=%232f81f7" width="24" height="24" align="absmiddle" /> Generador de constancias, certificados y credenciales

**Qué es:** una herramienta web que genera documentos oficiales con los datos de cada persona, con varios diseños intercambiables (ornamentos en SVG) que se cambian con un botón, y soporte de impresión/PDF. También se usa para armar credenciales escolares a partir de listas de alumnos en Excel.

**Qué resuelve:** elimina el trabajo manual de hacer cada documento uno por uno y da una presentación formal y consistente, lista para imprimir.

**Tecnologías:** React · SVG · impresión/PDF

---

### <img src="https://api.iconify.design/lucide/film.svg?color=%232f81f7" width="24" height="24" align="absmiddle" /> CineJuntos

**Qué es:** app web responsiva para que dos personas vean videos de YouTube en sincronía desde dispositivos distintos, con cuentas de usuario, lista de amigos y lista de videos por ver.

**Qué resuelve:** permite disfrutar contenido juntos a distancia, con reproducción y pausa sincronizadas en tiempo real.

**Tecnologías:** React · React Router · Firebase (tiempo real)

---

### <img src="https://api.iconify.design/lucide/dumbbell.svg?color=%232f81f7" width="24" height="24" align="absmiddle" /> Automatización de gimnasios con NFC

**Qué es:** sistema híbrido de control de acceso y gestión para gimnasios, con tarjetas NFC, microcontroladores ESP32 y una arquitectura web en Firebase. Se validó con un despliegue experimental de 6 semanas en un gimnasio y está documentado en un artículo académico enviado a revista.

**Qué resuelve:** automatiza el control de entradas y la gestión de usuarios, reduciendo el registro manual y el trabajo del personal.

**Tecnologías:** NFC · ESP32 · Firebase
